# Мои пары 72

Сайт: https://moi-pary72.github.io/moi-pary/

Официальный источник: [страница техникума](https://mck72.ru/learners/information-on-learning-process/training-schedules/),
[публичный Яндекс Диск](https://disk.yandex.ru/d/Xc08g8WbTavdHQ).
Сайт показывает текущую и следующую недели в часовом поясе Тюмени (UTC+5).

## Проверки и обновление

```sh
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python scripts/sync.py
# Полная повторная загрузка независимо от метаданных:
python scripts/sync.py --force-download
python -m http.server 8000
```

Workflow `sync.yml` запланирован на 17-ю и 47-ю минуты каждого часа UTC.
Это целевая частота примерно раз в 30 минут, а не гарантия GitHub Actions.
Ручной запуск: Actions → Refresh timetables from Yandex Disk → Run workflow.
Кнопка на сайте проверяет опубликованную копию, не запускает Actions.

При неизменённых modified/size/md5 используется ранее проверенная версия
того же парсера и недели. Не реже чем через 24 часа с последнего скачивания
файл загружается заново. Проверяются размер, MD5 (когда предоставлены),
формат XLS, шесть дат недели, группы, занятия и время. При потере групп или
более 40% занятий сохраняется прежняя версия и требуется проверка источника.
Новая версия структуры не принимается молча. Непубликация следующей недели
считается ожидаемой только пока папка отсутствует и нет предыдущих данных.

`schedules.json`: `last_changed_at` — последнее изменение содержимого
расписания, `generated_at` — формирование JSON. `sync-status.json`:
`last_attempt_at` — попытка; `last_successful_checks[неделя][отделение]` —
успешная проверка метаданных/скачивание; `checks` — результат последней попытки.
`downloaded_at` и SHA-256 в данных отделения фиксируют проверку самого XLS.
Ошибка не обновляет время успешной проверки и не затирает рабочую неделю.

Обновляющий процесс сначала сохраняет рабочие данные и честный статус,
затем возвращает ненулевой код при ошибке источника. Workflow публикует
сохранённые данные и статус, запрашивает сборку существующего GitHub Pages,
после чего отмечает ошибку задания. Права: contents:write, pages:write.
Публикация выполняется из main; отдельная тестовая ветка сайт не заменяет.
Браузер получает JSON с cache:no-store и уникальным параметром URL.

Неизвестный кабинет хранится как пустая строка и показывается «Не указан».
Реальные обозначения (`112А/1`, `АЗ/1`, `БКИ`, `ДО`) сохраняются.
Парсер xlrd читает сохранённые результаты формул, не вычисляет формулы.
Ошибки Excel отклоняют файл. Объединённые пустые ячейки не заполняются
выдуманными занятиями или кабинетами; повторяющиеся точные строки удаляются.
